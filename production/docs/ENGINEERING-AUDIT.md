# 自动化工程验收

审计日期：2026-10-27。范围：本分支的生产模块，以及 V1、V2、A/B、P3、Every Door 的实际源码与运行记录。此次没有制作新长视频。

## 结论

目前是**配置驱动、由 Codex 做语义导演的模板生产流水线**。它能编译和渲染明确的事件数据；没有实现“任意英文稿 + 任意配音 → 独立理解剧情与时代 → 自动创作视觉表演”的无人值守系统。此前说“换故事不用重写动画 JS”，只在现有模板语法内得到验证；不能扩大为不再需要逐镜头导演工作。

审计开始时，GitHub main 与本地 HEAD 均为上游 `d3d665301c0b62f04c885785e6bd6044de0785c6`。`production/` 和 `skills/story-production/` 都是未跟踪文件；网站交付曾保存源码 ZIP，但没有把代码提交到这个 GitHub 仓库。此次通过独立分支和 PR 持久化。

## 六个问题的直接回答

| 问题 | 实际答案 |
|---|---|
| 是否有通用命令？ | 有 `node production/cli.mjs run JOB.json`。输入必须包括已审核的 events.json；第一次在检查后返回 `review_required`，不会凭空生成完整语义分镜或自动通过看图。 |
| 换故事需要专用 JS/TS 吗？ | 注册表支持的故事只改文案、录音、事件、角色和素材数据。两篇固定样本已验证。新动作/新对象类别/新图表结构仍需扩展共享适配器，当前不能保证任意稿件都不改代码。 |
| 什么会自动生成？ | 给定事件后：实测/对齐音频时间、30fps 镜头边界、预设构图选择、角色实例、动作落点、空隙微动作、字幕词组、动作绑定音效、原引擎场景和 MP4、数值质检。 |
| 什么只会固定模板复用？ | 三套公寓/街道/地铁分层图、七个相机预设、有限姿态/IK/门/文档等对象、2–4 卡片箭头信息图、动作→音效映射和固定音乐风格配置。没有原创背景生成器或任意图解设计器。 |
| 什么仍由 Codex 逐镜头编写？ | 每镜头 purpose/kind/setting/actors/props/actions、语义先后、对象状态、年代标签、情绪对应动词与时机，必要的摆位配置和最终看图结论。现在主要写 JSON，而不是每镜头手写 JS；工作本身没有消失。 |
| Skill 是真实代码入口吗？ | 是。`scripts/produce.mjs` 实际启动 production/cli.mjs；Skill 还要求 Codex 进行语义规划和看图。它不是后台运行的语义模型，也不是只有一段提示词。 |

## 视觉智能化：尚未实现

- **地点**：`suggest` 只有 street/outside、station/train/subway 等少量正则；主要依赖 Codex 填 setting。没有地点实体识别、场景检索或未知场景生成。
- **年代**：没有年代资产索引、年代语义解析或历史美术生成。1912 与 2089 使用同一套现代风格街道；`year` 是文字标签。原片的年代环境生成验收应判为**未通过/未实现**，不能因为年份文字不同算成功。
- **人物身份**：身份 ID 和造型由配置指定。角色 token 一致性可检查；无法从文案自动理解“同一个人四十年后”并设计老年造型，Older Eli 是人工配置的身份变体。
- **情绪与表演**：由 `startle/hesitate/...` 映射到固定 pose/emote；没有自动情绪识别和表演规划。微动作填隙不等于角色在演剧情。
- **信息图与音效**：根据已指定的 kind/verb 选模板，没有理解规则后创作独立图解或声音设计。

当前三个背景均为通用/现代化示意资产；不能充当经过验证的历史或未来地点。空走廊复用带家具室内布景也是语义匹配不足，应该记录为资产缺口。

## 通用能力扩展与一次性定制

前几轮 scenes.js 是一次性导演实现，现归档为 legacy-source，不作为通用运行时依赖。Every Door 初次验证期间新增了共享门开关、文档对象、站位/可达和遮挡规则，这是**围绕样本提炼的通用扩展**，不能说第一次新故事从头就零开发。冻结后 Clock 样本只换数据没有改运行时；本分支再次用相同代码做两篇短复现。

没有新增年代美术组件；没有为本次两条验收输入新增剧情专属 JS。此 PR 中的代码修复是通用 I/O、可移植性、保护和证据整理。

## 下一阶段优先级

1. 语义事件提取与人工审查的明确契约：实体、地点、年代、身份、情绪、因果和支持度；先建立标注测试集，再引入规划器，避免把 regex 叫智能。
2. 具有地点/年代标签和版权来源的场景资产库，以及“缺少匹配资产就阻断/待审”的选择机制。先解决 1912 街景、未来街景和走廊，而非继续改年份文字。
3. 可验证的表演片段、对象交接和跨镜头状态；为每个共享模板记录覆盖测试，不以一个样片证明全部模板。
4. 语音内容核验、对齐置信与人工听审；技术信号存在不等于英语自然或语义同步。
5. 分段渲染、恢复、流式进度和大文件对象存储；之后才验证 3/10 分钟压力和批量稳定性。

## 持久化边界

分支保存源代码、Skill、独立配置、SVG/PNG 原创背景、小型 FLAC 输入、历史与本轮 JSON 证据和安装/运行说明。MP4、node_modules、.python、.stickman、临时日志和密钥不进入提交。历史源码中的绝对路径仅为考古证据；标准入口与新验收样本不依赖它们。
